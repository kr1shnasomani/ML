<h1 align="center">FaceFeel</h1>

Convolutional Neural Network (CNN) for facial emotion recognition using the FER-2013 dataset.

## Approach
- **Deep Learning**: Custom CNN architecture to predict emotions from cropped face inputs.
- **Outputs**: Classifies into emotions with confidence scores.

## Performance
Generates accuracy/loss graphs during training and evaluates on test datasets.

## Installation & Execution
```bash
cd FaceFeel
pip install -r requirements.txt
```
Open and run `code/main.ipynb`.
