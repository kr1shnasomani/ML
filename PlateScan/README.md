<h1 align="center">PlateScan</h1>

Detects and extracts text from vehicle number plates.

## Approach
- **Computer Vision**: OpenCV for image processing, contour detection, and cropping.
- **OCR**: EasyOCR for optical character recognition of the license text.

## Performance
Accurate text extraction from clear, well-lit vehicle images.

## Installation & Execution
```bash
cd PlateScan
pip install -r requirements.txt
python code/main.py
```
