<h1 align="center">CreditWise</h1>

Predicting credit card default probabilities to help lenders manage risk and minimize losses.

## Approach
- **Data Exploration**: Extensive EDA on historical payment data and demographic information.
- **Preprocessing**: Handling data scaling and balancing techniques (like SMOTE).
- **Modeling**: Implementing various classifiers including Logistic Regression, Random Forest, XGBoost, and LightGBM.
- **Evaluation**: Utilizing confusion matrices, classification reports, and ROC-AUC scores to determine the best predictive model.

## Performance
Achieves robust prediction accuracy on identifying potential defaulters, balancing precision and recall to manage financial risk effectively.

## Installation & Execution
```bash
cd Prediction-of-Credit-Card-Default
pip install -r requirements.txt
```
Open and run `code/main.ipynb`.
