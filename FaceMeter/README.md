<h1 align="center">FaceMeter</h1>

Real-time face detection tracking and displaying the percentage of visible facial landmarks.

## Approach
- **Landmark Tracking**: MediaPipe for robust facial mesh detection.
- **Video Processing**: OpenCV for webcam integration and real-time rendering.

## Performance
Optimized for real-time video feeds with low latency.

## Installation & Execution
```bash
cd FaceMeter
pip install -r requirements.txt
python code/main.py
```
