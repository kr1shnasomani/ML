# ML Projects

A consolidated repository containing various Machine Learning, Deep Learning, Computer Vision, and Natural Language Processing projects.

## Project Directory

### Computer Vision
* **FaceCapture**: Detects and crops faces using Haar cascade classifiers.
* **FaceMeter**: Real-time facial landmark detection using MediaPipe.

### Deep Learning & NLP
* **ToneSense**: Audio feature extraction and emotion classification using deep learning.
* **SentimentScope**: Text classification of IMDb movie reviews using LSTM and GloVe embeddings.
* **PlateScan**: Number plate text extraction using OpenCV and EasyOCR.

### Hybrid (CV + DL / NLP)
* **CaptionCraft**: Image captioning using DenseNet201 and LSTM.
* **FaceFeel**: Facial emotion recognition using a CNN.
* **Maskify**: Mask detection using a Caffe model and Keras classifier.
* **SpeedVision**: Vehicle detection, tracking, and speed estimation using YOLOv8.
* **StreetScanner**: Semantic segmentation of pedestrians and vehicles using DeepLabv3.
